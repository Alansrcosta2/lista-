Como começar

  1. Monte sua lista em casa adicionando produtos e quantidades.
  2. Toque em “Ir para Mercado” para registrar preços e marcar itens.
  3. Use o botão 🗺️ para localizar supermercados perto de você.
  4. Acompanhe tudo pelo menu ⋯ → Relatórios.

Dicas rápidas

  • 🌙 Alterne entre tema claro/escuro no ícone do cabeçalho.
  • 💾 Salve listas no menu para reutilizar em próximas compras.
  • 📦 Importe ou exporte dados para backup em um toque.

Sobre o Lista + 🛒

Aplicação PWA para planejar e realizar compras com recursos inteligentes.

Ajuda a organizar listas, registrar preços, tirar foto de produtos e encontrar lojas próximas.

🚀 Funcionalidades Principais:
  • Planejamento: Autocomplete, unidades e quantidades sugeridas, base local.
  • Fotos: Tirar foto do produto no botão ✏️ (cresce o banco de imagens).
  • Modo Mercado: Preço por kg/pack, pendências de peso e exclusão por lixeira.
  • Sincronização: Lista compartilhada em tempo real entre celulares (código de 6 dígitos).
  • Inteligência: Sugestões de recompra, rollover, orçamento.
  • Backup: Automático a cada 7 dias + exportar/importar.
  • Mapas: Busca supermercados próximos e navegação direta.
  • Relatórios: Gráficos de gastos e histórico completo.
  • Tema: Claro/escuro, PWA offline, instalável.

👨‍👩‍👧 Uso em Família (Sincronização)

Para usar com sua esposa em outro celular:

  1. Vá em Menu ⋯ → Exportar Dados.
  2. Envie o arquivo pelo WhatsApp para ela.
  3. No celular dela, ela abre o app e vai em Importar Dados.
  4. Escolha o modo "Merge" para juntar as listas sem apagar nada!

🔗 Conectar casal

Vocês dois digitam o mesmo código de 6 dígitos para compartilhar a lista em tempo real.

Como funciona: um de vocês clica "Gerar código" e passa os 6 dígitos para o outro (por WhatsApp, por exemplo). Os dois digitam o mesmo código e clicam "Conectar". A partir daí, qualquer item adicionado, editado ou comprado em um celular aparece no outro em segundos. Os dados ficam no Supabase (privado), não no git.
